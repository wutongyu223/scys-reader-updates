# 生财随读更新源

用于个人 Android 阅读器的推荐目录和安装包更新。只包含帖子标题、作者、原文链接、推荐说明和应用发布信息；不包含文章全文、登录信息、收藏、笔记或批注。阅读原文仍需生财有术账号及相应权限。

安装包：进入本仓库的 Releases，下载最新 APK，在原应用上覆盖更新。

## 目录更新

修改 catalog.json 的系列和文章信息，并递增 revision。保留已有系列及文章 id；文章编号必须为字符串。客户端先显示本地目录，再后台检查更新；网络失败或目录无效时保留上一次成功目录。

## 应用升级

将原签名的新 APK 上传到新的 Release，再更新 latest.json 中的 versionCode、versionName、downloadUrl、sha256 和说明。downloadUrl 指向确定版本的 Release 文件。应用内「设置 → 检查应用更新」提供下载入口，安装由 Android 系统处理。
